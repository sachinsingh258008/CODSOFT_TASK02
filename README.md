# Brewly ☕ — Specialty Coffee Landing Page

**CodSoft Web Development Internship — Level 1 (Task 2: Landing Page)**

A clean, responsive landing page for **Brewly**, a small-batch specialty coffee brand, built using semantic HTML5, modern CSS3 (Flexbox & CSS Grid), and lightweight vanilla JavaScript.

---

## 📁 Project Structure

```text
brewly-landing-page/
├── index.html      # Semantic HTML structure & sections
├── style.css       # Responsive layout, color palette, typography & animations
├── script.js       # Mobile navigation toggle, toast notifications & form handler
├── README.md       # Project documentation & submission steps
└── .gitignore      # Standard ignored files
```

---

## ✨ Key Features

- **Sticky Responsive Navbar** with mobile hamburger toggle
- **Hero Section** with brand value proposition, stats, CTA buttons, and a pure-CSS animated coffee cup illustration (no broken external images!)
- **About Section** highlighting direct-trade sourcing and small-batch roasting
- **Featured Products Grid** with roast tasting notes and interactive "Add to Bag" toast notifications
- **Why Choose Us** 4-column feature cards
- **Customer Testimonials** and **15% Off Lead Capture Form**

## 🚀 How to Run Locally

1. Extract the ZIP archive.
2. Open `index.html` directly in any web browser (or use VS Code **Live Server**).

## 🐙 Push to GitHub (`CODSOFT_TASKSNO`) & Deploy

1. Inside your local `CODSOFT_TASKSNO` repository folder, create a subfolder named `Task-2-Landing-Page` and paste all files inside it.
2. Run:
   ```bash
   git add .
   git commit -m "Add Level 1 Task 2: Brewly Coffee Landing Page"
   git push origin main
   ```
3. **GitHub Pages (Optional Live Link):**
   - Go to your repository **Settings → Pages**.
   - Under **Source**, select `Deploy from a branch` (`main` / `/root`) and save.
